# 🤖 Como surgiu o mascote do Android

Um site informativo sobre a história do sistema operacional **Android** e a evolução do seu famoso mascote, o **Bugdroid**, desde as primeiras versões até aos dias de hoje.

> Este projeto foi desenvolvido durante o curso de HTML5 e CSS3 do [Curso em Vídeo](https://www.youtube.com/cursoemvideo), lecionado pelo professor [Gustavo Guanabara](https://gustavoguanabara.github.io/).

---

## 📋 Sobre o Projeto

O site apresenta um artigo detalhado com as seguintes secções:
- **Origem dos Dandroids:** A primeira tentativa de mascote criada por Dan Morrill usando o Inkscape.
- **Criação do Bugdroid:** A versão definitiva criada pela ilustradora Irina Blok.
- **Curiosidades:** Vídeo explicativo e lista com o histórico das versões "adocicadas" do Android (do Cupcake 1.5 ao Pie 9.0), com ligação externa para o Android History.

---

## 🛠️ Tecnologias e Recursos Utilizados

- **HTML5:** Estruturação semântica (`<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`).
- **CSS3:** Estilização externa via `style.css`.
- **Imagens Responsivas:** Utilização da tag `<picture>` com suporte a múltiplos tamanhos (`media="(max-width: 670px)"`).
- **Mídia Integrada:** Incorporação de vídeo do YouTube (`<iframe>`).
- **Favicon:** Ícone personalizado configurado no `<head>`.
